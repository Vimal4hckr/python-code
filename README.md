# Python Programming Practice

A collection of Python programming exercises, Jupyter Notebook examples, and data structure implementations designed to help students develop programming and problem-solving skills.

## 📚 Topics Covered

### 1. 2D Arrays and Matrix Operations

This repository contains practical programs covering:

- Creating and initializing 2D arrays
- Reading and displaying matrix elements
- Accessing individual elements
- Calculating row sums and column sums
- Calculating the total sum of matrix elements
- Finding maximum and minimum elements
- Counting even and odd elements
- Searching for an element
- Reversing matrix elements
- Main and secondary diagonal operations
- Upper and lower triangular matrices
- Boundary traversal
- Spiral and wave traversal
- Matrix addition and subtraction
- Matrix multiplication
- Matrix transpose
- Rotating a matrix by 90 degrees

### 2. Data Structures

- **Linked Lists:** Learn linked-list concepts and implementation through the `linked_list_tutorial.py` tutorial.

## 🚀 Getting Started

### Step 1: Clone the Repository

```bash
git clone https://github.com/Vimal4hckr/python-code.git
cd python-code
```

### Step 2: Check Python Installation

```bash
python --version
```

### Step 3: Install Jupyter Notebook

```bash
python -m pip install notebook
```

### Step 4: Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file and execute the cells in order.

### Step 5: Run the Python Script

To run the linked-list tutorial:

```bash
python linked_list_tutorial.py
```

## 🎯 Learning Objectives

- Understand Python syntax and programming fundamentals.
- Develop problem-solving skills using arrays and matrices.
- Implement common matrix operations and traversal algorithms.
- Understand indexing, loops, and conditional statements.
- Explore data structures through Python implementations.
- Practise writing, executing, and debugging programs.

## 💡 How to Practise

1. Start with the first notebook and progress through the numbered exercises.
2. Run each program and understand its output.
3. Experiment with different inputs and matrix sizes.
4. Modify the examples to solve similar problems.
5. Try implementing each solution independently.
